# Gerador de Prompts de Personagem

App feito em React + Vite + Tailwind. Monta prompts completos de imagem para IA (formato, personagem, cena, regras de consistência e prompt negativo) a partir de um formulário guiado.

## Estrutura

- `index.html` — página raiz
- `src/main.jsx` — ponto de entrada do React
- `src/App.jsx` — o app inteiro
- `src/index.css` — ativa o Tailwind
- `package.json` — lista as dependências (React, Tailwind, ícones)

## Publicar no Vercel

Suba esta pasta inteira (mantendo a pasta `src`) para um repositório no GitHub e importe no Vercel — ele instala e builda tudo automaticamente.
